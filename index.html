Projects

RAG Document Q&A — Working Code

Personal project · github.com/bhavya-mummaneni/rag-doc-qa

Problem: answer questions grounded in a document set, with traceable sources. Approach: LangChain ingestion and chunking, FAISS vector search, answers composed from retrieved passages with source citations, FastAPI backend and Streamlit UI. Results (sample data): a 15-question evaluation — 100% retrieval hit rate and 100% answer accuracy. Limitations: generation is extractive because the project runs without an LLM API key; the design lets an LLM swap in without changing the API or UI.

More projects are in progress, including a LangGraph agent with tool calling and an evaluation harness.
